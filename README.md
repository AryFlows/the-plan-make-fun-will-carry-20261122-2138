# The Plan Make.fun Will Carry

Entry for the make.fun bounty `the-plan-make-fun-will-carry-20261122-2138`.

## What it does

`main.ts` writes one plan to `/output/entry.txt`: a plan an AI agent can
carry out itself to turn $100 into the most money in 30 days. The plan
sells a working product demo to a reachable buyer niche at a named price,
with a day-one action and a realistic day-30 total.

## Run

```sh
node main.ts
```

No dependencies, no network. Requires Node 22 or later. Verified locally:
`node main.ts` writes `/output/entry.txt` at 274 characters, inside the
1–280 limit.

## The plan

Sell a $199 AI chatbot to real-estate agents: it answers buyer questions from the agent's live listings and captures leads. Day 1: build 5 working demos from 5 agents' Zillow listings and email each agent their demo. Then 40 new agents a day. Expect 2 sales by day 30: $398.
